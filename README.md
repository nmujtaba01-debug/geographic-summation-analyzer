# Geographic Summation Analyzer

A Python project that calculates geographic statistics using loops, dictionaries, and summation techniques.

## Features

- Calculates Total Population
- Calculates Total Rainfall
- Calculates Total Mountain Height
- Uses Python Lists and Dictionaries
- Demonstrates For Loops and Summation (`+=`)

## Datasets Used

### Cities Population Data
- Delhi
- Mumbai
- Jaipur
- Shillong
- Chennai

### Rainfall Data
- Rajasthan
- Meghalaya
- Assam
- Western Ghats
- Ladakh

### Mountain Height Data
- Aravalli
- Kanchenjunga
- Nilgiri
- Everest

## Concepts Practiced

- Variables
- Lists
- Dictionaries
- For Loops
- Data Traversal
- Summation
- Basic Geographic Data Analysis
